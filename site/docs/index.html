Jev Flow combines typed Jev judgments with a code-owned workflow. The Studio is a local Node.js app; this GitHub Pages site is documentation and examples only.

Install and run

Requirements: Node.js 20 or later. Python 3.11+ is optional for the local Laya adapter.

git clone https://github.com/daltonrpj/jev-flow.git
cd jev-flow
npm ci
npm start

Open http://127.0.0.1:8723/jev/flows. Preview and fixture tests work without provider credentials. Connect TypeSafe or an OpenJev-compatible endpoint only when you want a live Jev judgment.

Credentials entered in the Studio stay in process memory and are cleared when the server stops. User flows, schedules, logs, and rulesets are saved outside this checkout.

Know which source answered

Fixture / previewSynthetic answers drive deterministic routing. No remote model was called.
Local adapterA separately installed, compatible local model ran. Its checkpoint and status must be shown.
Remote providerAn explicitly configured endpoint returned an observed, schema-valid answer. Usage and cost are shown only when supported by evidence.

A missing key, timeout, or malformed response remains unavailable or invalid. Unknown usage and cost stay unknown.

How a flow works

01 · InterpretA `jev.ask` node asks bounded Choice, Noul, or Score questions about the input.
02 · ValidateThe runtime checks the typed response schema and preserves provider/model provenance.
03 · RouteConditions, thresholds, budgets, verification, and review branches are explicit code-owned steps.

A model answer is evidence for a branch. It cannot authorize a payment, webhook, or other external effect by itself.

388,080 generated configurations

The Compendium generates candidates on demand from 22 patterns, 42 unique domains, 7 variants, 4 thresholds, 3 complexity levels, and 5 focus options. The certified count represents mechanically valid, unique configurations, not 388,080 hand-authored files or live model evaluations.

After changing catalog code, run npm run catalog:certify. The certificate includes counts, a source fingerprint, and a generation date; the landing page shows the total as verified only when this record matches the catalog.

Start with an example

Use the editable templates from the project’s examples folder: support triage, refund intake, spam screening, anomaly review, or a typed activity lesson. Each includes synthetic inputs and fixture answers, with local log actions for adaptation. The chess and Blast Garden boards are separate local Labs pages.

  • Run a deterministic fixture to inspect routing without a provider call.
  • Change input fields, thresholds, and review outcomes for your own policy.
  • Connect a provider and run live only when you explicitly want model output.

Security and data

The Studio server binds only to loopback and refuses remote binds. Flow definitions can contain private data, and bearer checks on API routes cannot protect a full browser session. Cross-origin mutations are rejected.

Secrets, provider keys, model weights, and user run logs do not belong in this repository. The only data-directory override is JEVFLOW_DATA_DIR. Read the full security guide and reporting policy.
