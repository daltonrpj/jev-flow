# Source, security, and contributions

Jev Flow is published as an independent repository at [github.com/daltonrpj/jev-flow](https://github.com/daltonrpj/jev-flow). The static site is documentation; the Node server is the runnable product.

## Source and license

The project is released under the MIT License. Read `LICENSE` and `THIRD_PARTY_NOTICES.md` before redistributing third-party dependencies or media.

## Security

Use the published repository's `SECURITY.md` and private reporting channel for vulnerabilities. Do not put credentials, personal data, private prompts, or exploit details in a public issue. The example editor runs in your browser, does not send its JSON to a provider, and does not store it in this site's backend.

A local application deployment may have different network and authentication boundaries. Verify them before exposing a server beyond loopback.

## Contributions

Use the published repository's `CONTRIBUTING.md` for tests and review standards. Keep examples generic, use synthetic data, label fixture versus real provider runs, and make side effects require explicit policy and authorization. A successful typed response is evidence for a branch, not permission to perform an external action.
